# Basic Encryption & Decryption

## Description

A Python implementation of the Caesar Cipher algorithm.

The program can:
- Encrypt text
- Decrypt text
- Demonstrate basic cryptography concepts

## Features

- Caesar Cipher Encryption
- Caesar Cipher Decryption
- User-defined Shift Key
- Handles Uppercase and Lowercase Letters
- Preserves Spaces and Punctuation

## Technologies Used

- Python

## Example

Input:
```
Message: Karim
Shift: 3
```

Output:
```
Encrypted: Ndulp
Decrypted: Karim
```
